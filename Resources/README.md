# Swarmbell artwork

The bell mark is original vector artwork made for Swarmbell. `Swarmbell.svg` is
the editable macOS icon source. The app bundle uses `Swarmbell.icns`; the iPhone
asset uses the same mark on a full square background so iOS supplies its mask.

The bell's paired signals represent agents reporting activity and asking for
attention. Source colors: honey `#f4cb62`, ink `#24362f`.
