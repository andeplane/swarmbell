# iPhone companion

Mode: Operate. Extends Swarmbell's existing native visual direction.

The first screen immediately distinguishes needs-you from working sessions.
Native navigation lists carry title, harness/project, state, freshness and source
coverage. No status is presented as an approval. Agent details keep readable
project paths and session IDs; actions stay owned by the original Mac harness.
Statistics preserves measured history and gaps with 24-hour/week/month/custom
ranges, harness filters, same-duration comparisons, activity series, hourly and
weekday histograms, weekday/hour heatmap, attention and source diagnostics.
Custom date edits request data only after Apply. Older Macs retain their standard
week/month reports; disconnected reports clearly retain their generated time.
All statistical controls are read-only. Connection is its own tab with explicit
QR/paste pairing, encrypted local-only scope and reversible forgetting.

Use system typography and semantic surfaces, blue interactive tint and orange
attention. Support dark/light appearance and Dynamic Type. No synthetic data,
decorative cards, fixed row heights, desktop URIs on the phone or clipped native
picker labels. Render checks must use native iPhone simulator/hardware output.
