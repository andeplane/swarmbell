# Swarmbell website

## Platform
Web, static HTML/CSS/JavaScript.

## Users and purpose
Developers running coding agents across Codex, Claude Code and Cursor. Explain the local macOS menu-bar monitor and let visitors try clearly labelled fictional agent states before downloading the free test build.

## Brand commitment
The user chose Swarmbell and explicitly requested an independent website similar to the public Workalong site. Warm editorial pacing, expressive serif emphasis, generous whitespace, an authored bell mark and a working product demonstration are pinned. The user approved the preview as beautiful. Preserve this visual direction.

## Product truth
macOS13+, Intel and Apple silicon universal build. Local five-second polling and SQLite measurement history. Attention-first navigation, statistics, optional read-only paired iPhone companion. Source availability and exact-chat routes vary by harness; see root README. Codex source-reported tokens are not actual dollar spend. No hosted collector, cloud agent data, website analytics, waitlist, account or payment collection. All browser demo data is fictional and stays in the browser.

## Release policy
Free while testing for a few days. A possible US$2.99 price is undecided, not an advertised purchase option. Initial download is ad-hoc signed and not notarized by Apple. Explain ordinary per-app macOS installation without disabling Gatekeeper or stripping quarantine.
