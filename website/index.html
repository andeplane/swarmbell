A few good questions.

Can I try it today?

Yes. Download the free macOS test build below. It’s an early release for Intel and Apple silicon Macs running macOS 13 or later. No account, email, or waitlist. We’re testing it before deciding on paid pricing.

Does it work with every agent session?

Coverage varies. Codex desktop observation uses a versioned private integration. Claude Code exposes supported polling. Cursor uses lifecycle hooks you can install from Settings, but native questions, approvals, and exact chat activation aren’t fully covered. Swarmbell shows limited coverage instead of pretending a missing source is idle.

Does it show tokens or costs?

Codex sessions show source-reported cumulative token totals when available. Cached input and reasoning tokens aren’t counted twice. Claude and Cursor totals and actual dollar spend aren’t available in this release.

What about the iPhone app?

The iPhone companion is included in the source repository and can be built with Xcode. It pairs privately with your Mac over the local network. It’s not on the App Store yet; this download is the Mac app.

Is the Mac download signed?

Yes. Swarmbell is signed with an Apple Developer ID and notarized by Apple. macOS verifies the signature when you first open the app.

Can I look at the code?

The full source is public on GitHub. You can inspect the integrations, build it yourself, and report a bug.
