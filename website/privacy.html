A little privacy.
Actually, quite a lot.

Swarmbell is a local observer for the coding agents you already run. Here’s what that means, without the fine-print voice.

Last updated November 17, 2026 · Test release 0.4.0

On your Mac

The app reads available local session and process metadata from supported Codex, Claude Code, and Cursor integrations. That can include a session title, project, status, source-reported token counters, and a way to return to the original conversation. The monitor does not send these observations to a Swarmbell cloud service or call a model API.

Refresh measurements and compact status history are kept in a local SQLite database. Measurement history does not store prompts, transcripts, tool arguments/results, session titles, or navigation commands. The current snapshot cache contains the metadata needed to show your current agents and is protected with private local file permissions.

Your optional iPhone connection

Sharing is off until you enable it. The paired phone receives a read-only snapshot and statistics from your Mac over an authenticated, encrypted local-network connection. Pairing credentials are stored in the devices’ Keychains. Keep pairing codes private: they grant access to the shared metadata. Reset pairing on the Mac to invalidate older pairings.

The companion does not run agents or answer approvals. This version has no Internet relay or background delivery service.

This website and its demo

The interactive demo uses fictional projects and browser-local state. It does not connect to your agents, ask for their credentials, or upload project data. Refreshing the page resets its example state.

We do not add website analytics, advertising trackers, an account system, or an email form. The hosting provider still processes ordinary request data, such as IP addresses, to serve and secure the website. Fonts are served from this website.

Downloads and feedback

Downloads, source code, and issue reports are hosted on GitHub and subject to GitHub’s privacy statement. Issues in the public repository are public. Remove private project names, pairing codes, transcripts, and credentials before attaching a report.

Inspect it yourself

You can read the full implementation and current integration limits in andeplane/swarmbell. To ask a question, open a GitHub issue without including sensitive information.
