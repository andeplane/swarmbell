Swarmbell icon provenance — 17 November 2026

Current icon is original vector artwork in Resources/Swarmbell.svg, not an ImageGen output. A honey background and dark ink bell use the same shape on macOS and iPhone; the Mac source includes its transparent outer margin, while iOS applies the system mask to the full-square asset. Resources/README.md documents source colors and generated files. The earlier 0.3.1 blue beacon artwork is superseded.
